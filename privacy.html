隐私政策（Privacy Policy）

核心准则：零用户活动日志留存（Strict Zero-Activity-Logs Policy） 最近更新：2026年10月
良心云核心隐私承诺：我们实行严格的零用户活动日志留存（Zero Logs）政策。我们的全部中转与落地服务器均采用无持久化日志的内存态（RAM-Only）运行架构，从物理与软件底层杜绝记录任何用户的上网行为历史。

一、我们绝对不收集与不留存的信息（零日志明细）

当您通过家庭软路由或个人终端连接良心云全球节点时，我们的系统绝不记录、绝不监控、绝不存储以下任何数据：

  • 不记录真实源 IP 地址：我们不会在节点服务器上保存您家庭宽带接入时的公网源 IP 地址；
  • 不记录网络浏览历史与目标网站：我们不知道您访问了哪些网站、调用了哪些 API 接口或观看了哪些流媒体内容；
  • 不记录 DNS 查询请求：所有加密通道内的内网 DNS 解析均在内存中瞬时完成，不写入任何磁盘日志文件；
  • 不记录传输数据内容与连接时间戳：所有业务流量均经过高强度端到端加密封装，任何中间节点均无法解密或窥探载荷内容。

二、维持账户运转所需的最小化必要信息

为了向您提供套餐订阅下发与账单核算服务，我们仅收集最小限度的账户元数据：

1. 注册电子邮箱：仅用于登录验证、接收订阅到期提醒与工单回复（您完全可以使用匿名邮箱注册）。

2. 汇总流量计数（Byte Counter）：系统仅统计账户在当前计费周期内消耗的总字节数（用于执行 1:1 真实流量额度核算），该统计仅包含纯数字体积汇总，不包含任何具体的访问目标或会话明细。

三、数据安全与第三方隔离准则

良心云不对任何第三方广告商、数据经纪机构出售、出租或共享用户邮箱数据。由于我们的服务器根本不产生、不留存任何用户上网活动日志，因此即使面临外部调阅请求，我们也无可提供任何与个人历史网络活动相关的记录。
